# Majlis app review (10 Oct 2026)

What I checked: played through home, setup, the ability draft, the board, questions, steals and answers on a phone-size and a desktop-size screen, read the game code, and ran checks over all 33,737 questions.

## Fixed in this round
- Arabic words now read "English - Arabic" on answers, and Arabic terms inside questions get the Arabic next to them.
- Abilities: 13 instead of 16, in three groups (Help, Points, Tactics). Each team picks one from each group, so every team has the same mix. Removed the overlaps: Time Freeze (same as Extra Time), Ease It (same as Swap, and it gave 600 points for a 200 question) and Risk It (same idea as Double Up). Extra Time is now 45 s, and Pickpocket takes half the tile's value instead of a flat 200.
- Stealing: every question now shows a Steal button for each other team, on any team's turn. Tapping it gives that team 15 seconds, and Block and First Steal work with it. Before, stealing only happened after the answer was already shown.
- Home screen counts now include the Wikipedia pictures and sound clips. On phones the board's Full screen button is hidden so the "whose turn" label fits.

## Suggested next (my order of value)
1. **Host screen.** Play on the TV, judge on a phone: the TV shows the question and the board, the host's phone shows the answer and the scoring buttons. This is the biggest upgrade for a real majlis night.
2. **Arabic interface option.** Menus, buttons and rules in Arabic, with right-to-left layout, chosen on the home screen.
3. **Question clean-up I can do now.** In 96 questions the answer appears in the question itself (for example "Which British team was founded by Sir Frank Williams?" with answer Williams), and 216 questions appear word-for-word in two categories, so they can repeat within one game. I can reword or remove these.
4. **Shorter games.** Let the host choose 4, 5 or 6 categories and 2 or 3 tiles per value, for a 20-minute game.
5. **Report a bad question.** A small flag button on the answer screen that saves the question to a list the host can send us, to catch wrong facts, broken pictures or clips with bad start times.
6. **Grow the new rounds.** The soundtrack categories stopped early (anime 81, games 61, film/TV 46) because of the web search limit, and Name That Logo has only 16 hard questions.
7. **Picture loading.** Pictures load from Wikipedia when a question opens. Preloading the board's pictures when the game starts would make them appear instantly and work better on weak Wi-Fi.
8. **Small polish.** The pop-up message sits over the score buttons on phones for two seconds; move it to the top. Add a confirm step on "No one" so a mis-tap doesn't lose a tile.

## Limits worth knowing
- The claude.ai web version blocks YouTube and probably Wikipedia, so clips and photos only fully work in the Android app.
- Clip start times and Wikipedia article titles were picked without listening or loading them, so expect a few to be off. Item 5 would help find them.
